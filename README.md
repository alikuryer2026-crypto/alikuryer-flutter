# Alikuryer Flutter

Android/iOS mijoz ilovasining boshlang'ich Flutter manba kodi. **Bu APK emas.**

## Ishga tushirish

Flutter SDK o'rnatilgan kompyuterda:

```bash
flutter create --platforms android,ios .
flutter pub get
flutter run
```

Android APK yig'ish: `flutter build apk --release`. APK: `build/app/outputs/flutter-apk/app-release.apk`.

Hozirgi versiya: demo ekranlar, haqiqiy SMS, to'lov va GPS ulanmagan.
